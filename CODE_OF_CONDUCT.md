# Code of conduct

BreatheWise is built for families, and we expect the same care in how we treat each other.

- Be respectful and assume good intent. Disagree about ideas, never about people.
- No harassment, discrimination or personal attacks, in any channel connected to the project.
- Welcome newcomers and explain decisions in plain language.

Maintainers may edit or remove contributions, and block participants who break these rules. Report problems
privately through a [GitHub security advisory](https://github.com/Harsha-code-per/BreatheWise/security/advisories/new)
or to the maintainer's GitHub profile. Reports are handled confidentially.
